# 网络诊断与隐私

本版仅在打开 App、授权返回或手动刷新时读取系统已经知道的网络信息；不发起 Wi‑Fi 扫描、测速或后台定位，不在后台定时采集。Debug 内网试验版可手动预览并提交独立的最小化报告；Release 仅本地采集与导出。小区授权与报告提交分开，授权不触发上传。

| 类型 | 采集范围 | 采集条件 |
| --- | --- | --- |
| 默认网络 | 活跃传输类型、互联网验证、计费、门户、系统估算带宽，以及 IPv4 / IPv6 默认路由类型、专用 DNS 状态（API 28+）、显式 MTU（API 29+，单位字节） | 普通 `ACCESS_NETWORK_STATE`。默认路由类型不证明互联网连通，估算带宽不是测速，MTU 未上报时留空 |
| Wi‑Fi | 当前主链路的频率（MHz）、频段、信道、RSSI（dBm）、协商速率、标准与安全类型 | Android 公开连接接口；默认网络须包含 Wi‑Fi。ROM 未上报则如实标注 |
| 蜂窝 | 默认数据订阅的注册运营商、SIM 运营商、PLMN、漫游与数据状态、调制解调器信号等级 | TelephonyManager 公开接口；具体值取决于服务及 ROM |
| 蜂窝数据制式 | 如 LTE、NR、IWLAN | Android 13+ 使用普通 `READ_BASIC_PHONE_STATE`；更早系统跳过此字段，不申请更广泛的电话权限 |
| 蜂窝小区无线参数 | 已注册小区的制式、LTE/NR 频段、信道号、参考频率与信号 | 用户可选授予精确位置权限，且系统位置开关开启；手动刷新时尝试公开小区更新，其余读取缓存；不请求 GPS，不导出小区 ID 或邻区列表 |

系统可能在 VPN 下仅公开部分默认路由信息。蜂窝订阅信息即使在 Wi‑Fi 上也可以存在，和默认路由分开展示；小区缓存是设备视角，未归属到独立 SIM，5G NSA 的辅小区不保证上报。Wi‑Fi 安全类型指当前连接协商的类型；Wi‑Fi 7 多链路场景不展示所有链路。

报告不采集 SSID/BSSID、MAC、IP、坐标、电话号码、IMEI、IMSI、SIM 序列号或用户账号。Android 将小区无线参数视为可能用于推断位置，因而要求精确位置权限。用户可拒绝，基础采集照常运行。JSON 含设备构建信息及运营商/无线参数，分享前请检查内容。

内网上报在预览中可展开查看白名单参数，包括实际 Wi-Fi 频率、信道、信号和协商速率，以及蜂窝制式、频段和信号等非标识参数。构建指纹、运营商名称及代码、精确小区信道/频点、坐标和小区标识仍只在适用的本地流程中处理，不进入上报。手机不使用邀请码或管理员令牌；服务端默认长期保存报告，不做自动过期清理。内网 HTTP 仅用于受控测试，传输不加密；远程部署前需改用 HTTPS。

LTE 下行参考频率按常见频段的 EARFCN 区间换算；未内置的区间仍显示原始信道号而不推测频率。5G NR 使用 NR-ARFCN 全局栅格得到参考频率，不等于频谱测量。频段与带宽是否可用取决于系统返回；2G/3G 不推测 MHz。导出的完整 1.x 结构不变，部分字段新增可选 `reason`。

Android 10+ 手动刷新会在有精确位置权限且系统位置已开启时调用一次 `requestCellInfoUpdate`；最多等待 2.5 秒，失败、超时或无注册小区时回退缓存。成功回调仍可能是缓存；小区字段展示系统采样年龄。如只读到 B3 等频段，会另显示标准下行范围；它不替代信道号、载波中心频率或配置带宽。移动数据开关、蜂窝数据连接、默认上网路由分别展示。

`RESTRICTED` 表示权限、系统开关或策略阻止读取；`UNAVAILABLE` 表示无适用数据或系统未回报；`ERROR` 表示读取异常。`errno=13 (EACCES)` 的 SELinux 节点与网络运行时权限无关，授权网络诊断后也不会改变。

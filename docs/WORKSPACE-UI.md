# 后台工作台：页面职责与验收

一级入口分为报告档案和资产管理。报告档案按采样查阅。资产管理按设备归组，提供顶部去重统计、批量报告管理、字段覆盖、身份分布和回收站。

打开报告后，使用页头的「查看参数」「单份安全分析」「打开验收工作台」切换当前样本的操作。安全分析解释当前样本的风险依据。验收工作台设置目标和同机基线，核对实验并导出证据。面包屑回到报告详情或发起入口，从列表打开的报告会恢复原位置。旧的 `#security`、`#lab`、`#identity` 入口仍可使用。

## 页面入口

| 页面 | 放在首屏的内容 | 后续操作 |
| --- | --- | --- |
| 报告档案 | 搜索、Android／API／品牌／型号／设备代号筛选、匹配总数与采样列表 | 打开报告后查看参数及来源、下载 JSON 或做单份安全分析 |
| 资产管理 | 全库统计、设备档案（默认） / 在库报告 / 字段覆盖 / 回收站 | 筛选后整批导出；勾选后显示归组、对比、导出或回收动作 |
| 指纹安全 | 当前样本或选样入口 | 查看证据；显式选择同机基线或对照其他设备；不作硬件认证 |
| 身份分布 | 全库概览、多身份资产、跨资产同一声明、内部冲突报告 | 打开报告或资产档案；导出 JSON；只读统计 |
| 构建中心 | 当前内网发布、工作进程状态、构建记录 | 主动打开构建表单，指定已登记源码及版本；独立下载和确认发布 |
| 应用下载 | 当前版本、兼容范围和 APK 下载 | 展开内部版本号、哈希和签名信息；该页无需管理令牌 |
| 设置 | 服务器接收、本浏览器偏好 | 接收改动明确保存或放弃；浏览器刷新频率单独保存 |

### 查一份报告

从顶部分类缩小报告范围。进入详情后，默认显示参数搜索与归档读数；「采样条件」集中展示采样时间、网络、版本、反馈和验收证据。

1. 在档案、资产管理或设备采样中打开报告。所有尺寸都用整块工作区读这一份报告；不在旁边留一个列表，也不在参数内另设纵向滚动条。
2. 找已知参数用搜索（如 `cellular.dataRat` 或 `errno=13`），按模块浏览用「定位分类」。列表默认展现所有实际归档的分类；小屏将值放到参数名下方，长值自然换行。状态旁有文字，不只靠颜色。
3. 受限、未上报等先显示报告记录的原因；点整行「依据」可核对完整字段键、来源、原因码、errno 与说明。历史报告只有状态时不生成参数。切换到「手机快照覆盖」再回来会保留本报告的搜索与状态筛选。
4. 从列表进入后，使用阅读页顶部的返回按钮回原入口；浏览器后退则按实际路径往回走。从列表直接进详情再后退时，两种返回都恢复页码、原行和焦点。分享链接不携带其他人的阅读位置。主导航仍用于主动换工作区。

### 范围与联动

- 全库统计按已归组的设备数和报告数分别计数。未归组报告不能折算为实际设备数。分类分布按报告显示；同一手机跨 Android 版本或批次时，分类设备数不相加。
- 报告档案跳到管理或字段覆盖时带上报告筛选。资产的在库、覆盖和回收站之间沿用报告条件；设备清单独立搜索。主导航总是指向默认入口。
- 资产批量操作只针对明确勾选的当前页记录。「导出筛选结果 ZIP」按实际筛选匹配所有页，不受当前勾选影响，但仍受服务端 250 份／32 MiB 单次导出上限约束。
- 裸入口 #assets 按设备一行展示，行内份数是采样数。#assets?tab=reports 是未筛选的报告管理；旧的批次或资产筛选书签仍进入报告管理。报告档案 #reports 逐份显示。
- `#assets?tab=devices&sampleAsset=<uuid>` 打开指定设备的采样列表。刷新或从报告详情使用浏览器后退可回到这个设备；URL 不保存临时勾选。
- 有效状态、空结果、读数受限和报告未归档分别展示。界面文字不是 API 契约；自动化使用原始 JSON 和 `group + key`。

### 身份提示

报告详情在归档参数前显示「身份声明不一致」提示（三对声明中任一对两侧都有值且不同），列出字段与两值并链接到 `#identity`。设备风险画像在 `identity_conflict` 命中时在顶部提示。两者都不改变报告或风险分级。

### 身份分布（`#identity`）

用概览卡片定位相应明细。表格按可用宽度切换为窄屏纵向记录，保留字段名。服务端截断时，页头说明哪些数字只代表已列项。

概览显示在库报告、已归组设备、多身份资产、跨资产同身份与内部冲突报告数；三张表分别列出多身份资产（每套声明、份数、最近报告）、跨资产同一声明（设备数、报告数）、内部冲突报告（采样时间、冲突对、报告与资产链接）。只读，可导出 JSON；声明不等于物理设备认证。

## 实现与验收

- `backend/web/src/workspace-ui.tsx` / `workspace-ui.css` 持有公共导航、页头、子页链接和空态组件。各业务页保留自己的数据请求、标签及工作流；新增一级页面应复用这些公共组件。
- `workspace-route.ts` 集中管理报告筛选、详情标识、资产子页和复测入口。导航使用链接，筛选控制和写操作使用原生表单控件，不用可点击的布局元素代替。
- 验收覆盖桌面侧栏、窄屏可折叠导航、键盘可见焦点、同页筛选与浏览器历史。用独立合成批次检查 ZIP、回收／恢复、设备采样深链接和复测；构建中心的预发布确认可用浏览器响应夹具检查，不触发真实发布。

### 复现阅读页回归

先运行 Web 单测和生产构建。浏览器回归从仓库根目录执行，使用 Node、Playwright 和本机 Chrome；若 Playwright 不在默认模块搜索路径，可通过 `NODE_PATH` 指向单独安装的测试依赖。该依赖不需要打进后台镜像。

```powershell
$env:SIGMARK_QA_URL = 'http://192.168.1.114:48272'
$env:SIGMARK_QA_BROWSER = 'chrome'
$env:SIGMARK_QA_OUTPUT = 'D:\SigMark\app\build\lan-qa\reader-focused' # 可省略
node backend/web/qa/report-reader.cjs
```

脚本拦截 API，仅使用本地响应夹具：65 份报告、跨页游标、126 项参数、旧协议及错误状态。检查浏览器前台真实布局、分类搜索、键盘展开、返回焦点与滚动偏差，不验证数据库写入。

如需核对某份**现有归档**，在同一环境另设本地会话变量 `SIGMARK_QA_TOKEN`，执行 `node backend/web/qa/check-archived-fields.cjs <报告UUID> [更多UUID]`。第二个脚本仅 GET 指定后台，对每个归档字段校验页面的键、值、状态和来源；只打印数量，不保存或打印参数值。它不验证手机本地快照，也不重新上传。
